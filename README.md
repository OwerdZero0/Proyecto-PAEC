Esto es lo que contiene los archivos:

1. Los archivos con terminación .html son los que tienen el codigo html con la estructura de la pagina web, y el acomodado del codigo, todos los html se encuentran afuera de todas las carpetas, el mas importante es el index.html, ya que es el primer html que se lanza y con el que inicia toda la pagina web
2. La carpeta Styles, contiene los archivos css de cada html, son los archivos que le dan estilo a todos los html
3. La carpeta Scripts, contiene los archivos js que hacen interactivas las paginas web que lo necesitan
4. La carpeta Traducciones i18n dentro de Scripts, Es la carpeta que contiene todas las traducciones de todas las paginas, para que se pueda traducir a español, ingles y nahuatl
5. La carpeta Multimedia, es la que tiene las imagenes, audios y videos usados en toda la pagina web, en ella hay subcarpetas que especifica a que html pertenece cada uno
6. El archivo php, es la base de datos de la pagina web del archivo Formulario.html
